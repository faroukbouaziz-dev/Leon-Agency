# Agency Marketing Website

Marketing website for a creative agency. Showcases the agency, its services, portfolio, and offers contact and AI chatbot assistance. Helps the agency build an online presence and generate leads.

[Live Demo](https://leon-agency-faroukdev.vercel.app/)

---

## Features

- Responsive URL-based navigation per section
- Dark/Light mode toggle
- Call booking functionality
- AI chatbot assistance
- Interactive sliders for portfolio and testimonials
- Email-integrated contact form
- Google Analytics integration
- Aesthetic animations
- Smooth performance
- SEO optimized
- 100% accessible (a11y compliant)

## Running Locally

Clone the project

```bash
  git clone https://github.com/faroukbouaziz-dev/Leon-Agency.git
```

Go to the project directory

```bash
  cd my-project
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run start
```
